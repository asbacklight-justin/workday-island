# 实时聊天与窗口互动

[中文](REALTIME_CHAT.zh-CN.md) · [English](REALTIME_CHAT.md)

## 使用方式

1. 点击主窗口顶部的聊天按钮。
2. 选择“一键登录”时，可修改昵称并创建匿名设备身份；选择“账号密码”时，输入已有账号的用户名和密码。没有账号时可点击“立即注册”创建账号。
3. 上线后可输入精确用户名或用户 ID 发送好友申请；收到申请时可同意或拒绝，好友列表会展示当前在线状态。
4. 点击好友即可开始会话，也可继续手动输入用户 ID。文字消息和“抖动窗口”“闪烁窗口”指令都支持离线补发；窗口互动可附带最多 120 个字符的提示语。
5. 点击“下线”会关闭实时连接。匿名设备身份仍保留在本机；账号密码会从会话内存清除，下次上线需要重新输入。“重置身份”只用于匿名设备模式。

对方暂时离线时，文字消息和窗口互动由服务端记录，并在对方下一次上线后补发。新消息到达时，聊天页会自动定位到最近发信人的会话。接收窗口互动时，工位岛会恢复、置前，展示发送者的提示语，并执行短暂抖动或彩色闪烁；用户可立即停止效果。

## 登录方式与安全

首次点击上线时，应用在本机生成 Ed25519 密钥对，并向 Backlight 实时服务注册匿名设备身份：

- 服务器只接收公钥、设备 ID、设备名称和显示昵称；
- 私钥不离开本机；
- macOS 私钥保存在系统钥匙串；
- Windows 私钥通过当前用户的 DPAPI 加密；
- 后续上线通过签名服务端随机挑战完成。

账号密码模式同样在收到服务端随机挑战后认证，并遵循以下规则：

- 注册入口复用 Backlight 账号服务，核心字段包括用户名、昵称、密码、确认密码，以及可选的邮箱、手机号和邀请码；
- 用户名须为 3–20 位字母、数字或下划线，昵称为 2–20 个字符，密码为 6–20 个字符；
- 注册请求通过 `https://admin.asbacklight.cn/api/user/register` 加密传输，注册来源标记为 `workday-island`；
- 注册成功后只回填用户名并切回账号登录，密码和确认密码立即从注册表单清除；
- 只通过加密的 `wss://` WebSocket 消息发送，不放入 URL 查询参数；
- 密码只保留在当前在线会话的内存中，用于临时断线自动重连；
- 主动下线、认证失败或退出应用后立即清除，不写入 `data.json`、系统钥匙串或 DPAPI 文件；
- 用户名可在本机记住，便于下次填写。

好友关系和好友申请由实时服务持久化。每次认证成功或断线重连后，客户端都会重新同步待处理申请和好友列表，并通过实时推送更新好友新增、删除和处理结果。

本机业务数据（待办、提醒、薪资、工作时间、天气设置和专注记录）不会发送到实时服务。

## 网络与故障排查

桌面端通过 `wss://admin.asbacklight.cn/api/realtime/ws` 建立加密 WebSocket 连接；匿名模式还会通过 `https://admin.asbacklight.cn/api/realtime/bootstrap` 完成首次设备注册，账号注册通过 `https://admin.asbacklight.cn/api/user/register` 完成。

如果界面提示“实时服务网关暂未启用 WebSocket”，说明 HTTPS 网关没有正确转发 WebSocket Upgrade，而不是一键身份或密码错误。Nginx 代理至少需要：

```nginx
proxy_http_version 1.1;
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
```

应用会在非认证故障后按 1、2、4、8、16、30 秒的节奏自动重连；主动下线后不会重连。

完整数据说明见 [隐私说明](PRIVACY.zh-CN.md)。
