# 工位岛 v0.16.9 / Workday Island v0.16.9

本版本聚焦英语阅读可读性、深色云笔记，以及实时聊天互动与聊天时间的体验完善。

This release improves textbook readability, Cloud Notes in dark themes, and realtime chat interactions and timestamps.

## 中文

### 教材课文

- 新增小、中、大三档正文字号，默认使用中号并自动保存在本机。
- 字号同时作用于英文原文、中文译文和本课词汇，三档差异清晰可见。

### 云笔记深色主题

- 修复普通深色、极光、Plus、Pro、Ultra 深色会员主题下云笔记局部使用浅色表面的问题。
- 导航、空状态、富文本/Markdown/表格编辑器、标题框、工具栏和操作按钮现在都会随深色主题显示，并保持足够对比度。

### 实时聊天

- 抖一抖和闪一闪新增互动表情面板，可仅发表情、仅发文案或发送表情加文字。
- 互动的表情与文案会完整写入双方聊天记录，并在接收方窗口提示中原样展示。
- 聊天时间更清晰：今日消息仅显示时分，非今日消息显示完整年月日与时分；普通消息和互动记录均适用。

## English

### Textbooks

- Added Small, Medium, and Large reading sizes. Medium is the default and is remembered locally.
- The setting scales English source text, Chinese translations, and lesson vocabulary together with visibly distinct levels.

### Cloud Notes dark themes

- Fixed light Cloud Notes surfaces that remained visible under standard dark, Aurora, Plus, Pro, and Ultra dark member themes.
- Navigation, empty states, rich-text/Markdown/spreadsheet editors, title fields, toolbars, and action buttons now follow the active dark palette with readable contrast.

### Realtime Chat

- Shake and Flash now have an interaction emoji picker. Send an emoji, text, or both together.
- The exact emoji and text are retained in both chat histories and shown in the receiver's window interaction prompt.
- Timestamps now show only time for today's messages and a full date plus time for earlier messages, for both normal and interaction records.
