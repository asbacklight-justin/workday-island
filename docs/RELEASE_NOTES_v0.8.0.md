# 工位岛 v0.8.0 · Workday Island v0.8.0

## 中文

本次版本新增“今日英语学习”模块，在不打断当前工作的前提下，用一块自动贴合内容的小窗口完成每日单词练习。

- 点击主界面的英语学习按钮即可打开独立学习窗口。
- 支持中英学习、英译中四选一、中译英四选一和完整单词拼写四种模式。
- 选择或提交答案后立即展示正确或错误，并显示正确答案。
- 练习过程中保留上一词的英文与中文，方便快速回顾。
- 四选一模式支持数字键 `1`～`4` 快速作答。
- 窗口会根据单词、释义和选项自动调整宽度；操作区靠左、最小化按钮靠右，尽量不保留无用空间。
- 通过词灵游客身份在线获取单词，每批最多 30 词，并提交单题练习结果。
- 设置中新增词库选择，默认《新概念英语》第二册。
- 可切换《新概念英语》第三册、大学英语四级、大学英语六级、雅思核心词汇和全部公共词库。
- 英语窗口沿用精简模式透明度设置，支持中文、英文及跟随系统语言。
- 修复 macOS App 与 Dock 图标可能显示为默认占位图的问题。

## English

This release adds Today English Learning: a small content-fitting window for daily vocabulary practice without taking over the desktop.

- Open the dedicated learning window from the English button on the main dashboard.
- Choose bilingual study, English-to-Chinese multiple choice, Chinese-to-English multiple choice, or full-word spelling.
- See immediate correct/wrong feedback and the correct answer after each response.
- Keep the previous English word and Chinese meaning visible for quick review.
- Use number keys `1`–`4` to answer multiple-choice questions.
- The window fits its width to the current word, meaning, and choices, with controls aligned left and Minimize kept on the right.
- Fetch up to 30 words per batch through Word Spirit guest access and submit individual practice results.
- Select a word library in Settings; New Concept English 2 is the default.
- Switch to New Concept English 3, CET-4, CET-6, IELTS core vocabulary, or all public words.
- The English window shares compact-mode opacity and supports Chinese, English, and system-language selection.
- Fixed the macOS app and Dock icon occasionally appearing as a generic placeholder.
