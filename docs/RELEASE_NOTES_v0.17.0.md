# 工位岛 v0.17.0 / Workday Island v0.17.0

本版本正式向已登录用户开放钓鱼小岛，并将核心鱼获进度升级为账号资产。

This release opens Fishing Island to signed-in users and upgrades core fishing progress into account assets.

## 中文

### 开放钓鱼小岛

- 登录后即可进入摸鱼岛，并使用开放的「钓鱼小岛」。
- 支持时机钓鱼、20 种鱼的永久图鉴、折叠鱼获背包、鱼竿装备与常见/珍稀/史诗/传说品质标签。
- 鱼获背包、永久图鉴、鱼竿、等级、经验与摸鱼币会自动同步到工位岛账号；已有本机数据首次登录时会迁移。
- 喂食或摸鱼小游戏消耗鱼获时，仅扣减背包数量，不会删除已解锁的永久图鉴。
- 摸鱼小岛、小宠舱与摸鱼农场仍为会员内测内容，需要 Plus、Pro 或 Ultra 会员；未满足权限时会显示明确提示。

## English

### Fishing Island is open

- Sign in to enter Slack Island and use the open **Fishing Island**.
- It includes timing catches, a permanent 20-fish compendium, stacked catch inventory, rod equipment, and Common/Rare/Epic/Legendary labels.
- Catch inventory, permanent discoveries, rods, level, XP, and slack coins now sync to the Workday Island account. Existing local data migrates on first sign-in.
- Feeding a pet or using a fish in a slack activity decreases only the inventory quantity; it never removes the permanent discovery.
- Slack Island challenges, Pet Cabin, and Slack Farm remain Plus/Pro/Ultra member-beta features, with a clear requirement prompt.
