# 工位岛 v0.16.12 / Workday Island v0.16.12

本版本优化钓鱼小岛的收纳、图鉴与操作布局。

This release refines the Fishing Island inventory, collection, and interaction layout.

## 中文

### 钓鱼小岛优化

- 鱼类图鉴不再占用顶部 Tab，改为钓鱼湖面内的图鉴入口；点击后在弹窗中查看 20 种鱼的解锁进度。
- 鱼获记录升级为「鱼获背包」：同类鱼自动折叠，直观显示数量。
- 喂食摸鱼小宠或在摸鱼小游戏中使用鱼获后，对应背包库存会即时减少。
- 钓鱼桌重新排版：背包与鱼竿装备/钓鱼指南分别置于湖面两侧，操作更集中，湖面更清爽。

## English

### Fishing Island polish

- The Fish Collection no longer uses a header tab. Open it from the lake to view progress for all 20 fish in a dedicated modal.
- The catch history is now a stacked **Fish Inventory**, making duplicate quantities easy to see.
- Inventory quantities update immediately after feeding a desk pet or using a catch in the Slack mini-game.
- The fishing desk has been rearranged so the inventory and rod/guide panel sit on opposite sides of a clearer central lake.
