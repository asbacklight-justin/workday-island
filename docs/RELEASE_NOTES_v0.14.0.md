# 工位岛 v0.14.0 · Workday Island v0.14.0

## 中文

`v0.14.0` 集中完善云笔记文档能力与工作台顶部入口管理。

### 云笔记文档类型

- 点击“新建笔记”后可选择普通笔记、Markdown 或表格文档，不再直接创建固定类型。
- Markdown 文档支持源码编辑与安全预览，可在桌面端和 Web 端之间继续编辑。
- 表格文档采用与 Backlight Web 后台一致的 Workbook 数据格式，支持单元格编辑、公式栏、增加行列与多工作表。
- 创建、自动保存、字数/单元格统计、AI 整理与翻译会根据文档类型正确处理内容。

### 可配置顶部入口

- 设置页最上方新增 AI、实时聊天、股市、工作云盘、云笔记、链接分享、全能翻译和英语学习八个独立开关。
- 所有入口默认显示；从旧版本升级时会自动补齐默认配置。
- 关闭开关只隐藏工作台顶部快捷入口，不会删除数据或停用对应功能，账号中心等入口仍可继续使用。

### 安装包

- **macOS 12+**：`Workday-Island-v0.14.0-macOS-universal.dmg`，同时支持 Apple Silicon 与 Intel。
- **Windows 10/11 x64**：`Workday-Island-v0.14.0-windows-x64-Setup.exe`。
- 使用 `SHA256SUMS.txt` 校验下载文件。

安装包尚未使用商业代码签名证书。请只从本项目 GitHub Release 下载；macOS 首次启动可在 Finder 中右键选择“打开”，Windows 可能显示 SmartScreen 提示。

## English

`v0.14.0` expands Cloud Notes document support and makes dashboard header shortcuts configurable.

### Cloud Notes document types

- **New Note** now asks whether to create a Rich Text, Markdown, or Spreadsheet document instead of immediately creating a fixed type.
- Markdown documents provide source editing and safe preview and remain editable between the desktop and Web apps.
- Spreadsheet documents use the same Workbook data format as Backlight Web, with cell editing, a formula bar, expandable rows/columns, and multiple sheets.
- Creation, autosave, statistics, AI hand-off, and translation process each document type correctly.

### Configurable header shortcuts

- The first section in Settings adds independent controls for AI Chat, Realtime Chat, Stocks, Work Cloud, Cloud Notes, Link Sharing, Universal Translator, and English Learning.
- All shortcuts are visible by default, and upgrades from older versions automatically receive the complete default configuration.
- Turning off a shortcut only hides it from the dashboard header. It does not delete data or disable the module, and other entry points such as Account Centre remain available.

### Packages

- **macOS 12+**: `Workday-Island-v0.14.0-macOS-universal.dmg`, supporting Apple Silicon and Intel.
- **Windows 10/11 x64**: `Workday-Island-v0.14.0-windows-x64-Setup.exe`.
- Use `SHA256SUMS.txt` to verify downloads.

The packages are not yet signed with commercial distribution certificates. Download only from this project's GitHub Release. On macOS, right-click and choose **Open** on first launch; Windows may display a SmartScreen prompt.
