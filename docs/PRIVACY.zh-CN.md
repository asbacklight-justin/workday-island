# 工位岛隐私说明

[中文](PRIVACY.zh-CN.md) · [English](PRIVACY.md)

更新日期：2026-07-28

工位岛采用本地优先设计。待办等核心功能不要求注册账号；聊天、好友和工作云盘使用统一的 Backlight 账号登录会话。

## 本机保存的数据

以下内容保存在用户配置目录中的 `WorkdayIsland/data.json`：

- 待办标题、备注、完成状态和提醒时间；
- 上下班时间、工作日、月薪与月计薪天数；
- 天气城市、界面语言、主题、英语词库、货币符号、置顶、精简模式透明度与待办选项，以及上次调整的精简窗口尺寸；
- 最近一次成功获取的天气结果，仅用于断网时回退展示；
- 股市小窗的自选代码；最近一次行情仅在应用进程内缓存，用于短暂断网回退；
- 最近一次成功检查更新的时间，用于将自动检查频率限制为每天一次；
- 当前专注会话的开始、结束和运行状态。
- 实时聊天的用户 ID、用户名、显示昵称，以及最多 500 条最近实时消息和窗口互动记录。
- 内嵌 WebView 可记住最近填写的账号用户名；账号密码和云盘访问令牌不会持久化保存。

应用不会上传待办、薪资、工作时间或专注记录。卸载程序不会自动删除数据文件，以便重新安装后继续使用；如需彻底清除，请退出应用后手动删除 `WorkdayIsland` 配置目录。

## 联网行为

天气功能会把用户填写的城市名称发送给 Open-Meteo 地理编码服务，再使用解析出的经纬度查询当前天气。股市小窗会把自选的公开证券代码发送给东方财富公开行情服务，以获取最新价格、涨跌额、涨跌幅和行情时间；不会发送姓名、账号、待办或薪资数据，行情仅供参考。版本检查会访问本项目公开的 GitHub Releases API，读取版本号、更新说明和安装包地址；不会发送待办、薪资或其他本机业务数据。自动版本检查每天最多一次，也可在“关于”页手动触发。禁用网络不会影响待办、提醒、倒计时和专注功能。

用户主动提交注册表单时，应用会将用户名、昵称、密码、确认密码，以及用户自愿填写的邮箱、手机号和邀请码发送到 `https://admin.asbacklight.cn/api/user/register`；邀请码为选填。登录时用户名和密码通过 HTTPS 发送到账号服务，并用于建立加密 WebSocket 会话。注册成功后仅用户名可由内嵌 WebView 记住；密码与访问令牌只保留在应用进程内存中，退出账号或应用后清除，不会写入本机配置、钥匙串或 DPAPI 文件。

账号登录后，应用会连接 `admin.asbacklight.cn`。聊天消息、发送者/接收者用户 ID 与昵称、发送时间、送达与已读状态、好友申请与关系、在线状态，以及抖动/闪烁指令会经过实时服务并可能由服务端持久化。抖动和闪烁也会作为会话互动记录保存在本机最近消息中。禁用网络不会影响聊天以外的本地核心功能。

用户打开英语学习时，应用会向 Backlight 英语服务请求所选公开词库中的单词、音标、释义、例句和选项，并提交单题结果。选择“例句学习”时，英文例句会发送到翻译接口以获取中文翻译；应用会在当前进程中缓存已获得的翻译，不写入本机数据文件。

用户打开工作云盘时，应用会使用当前账号令牌读取目录与存储配额。只有在用户主动选择上传文件后，应用才读取所选文件并将其上传到服务端签发的对象存储地址；下载同样由用户主动触发。文件名、大小、类型、目录关系和对象键会由 Backlight 服务保存，文件内容存放在配置的对象存储中。应用不会遍历或扫描未被用户选择的本机文件。

## 系统能力

应用会使用系统通知、文件选择/保存对话框、提示音和窗口置前能力来执行提醒、云盘传输与用户主动发送的窗口互动。它没有遥测、行为分析、广告 SDK 或联系人/日历读取，也不会扫描未由用户选择的其他文件。
