# 工位岛 · Workday Island

[中文](README.md) · [English](README_EN.md)

一款常驻桌面的轻量工作助手：把时间、下班倒计时、天气、待办、持续提醒、专注计时、英语学习、全能翻译、好友聊天和工作云盘集中到一座安静的“工位岛”上。

![工位岛中文主界面](docs/screenshots/zh-main.png)

## 下载与安装

前往 [GitHub Releases](https://github.com/asbacklight-justin/workday-island/releases/latest) 下载最新版。

| 平台 | 安装包 | 支持范围 |
| --- | --- | --- |
| macOS | `Workday-Island-v0.11.0-macOS-universal.dmg` | macOS 12+，Apple Silicon（M 系列）与 Intel |
| Windows | `Workday-Island-v0.11.0-windows-x64-Setup.exe` | Windows 10/11 x64，依赖 Microsoft Edge WebView2 |

当前公开安装包未使用商业代码签名证书：macOS 首次运行时可在 Finder 中右键应用并选择“打开”；Windows 可能显示 SmartScreen 提示，请确认文件来自本项目的 GitHub Release。请不要从未知转载站点下载安装。

## 核心功能

- **桌面置顶**：主窗口可随时置顶，让倒计时与待办始终触手可及。
- **系统托盘常驻**：点击叉号隐藏窗口后，待办与专注提醒仍在后台运行；左键托盘图标恢复，右键菜单可彻底退出。macOS 菜单栏拥挤导致图标被系统遮挡时，也可点击保留的 Dock 图标恢复窗口。
- **精简模式**：隐藏标题头，采用 2×2 核心卡片布局；窗口可在 400×270 至 900×600 之间调整并记住尺寸，内部字号、间距与组件同比缩放；支持 30%–100% 透明度并可选展示未完成待办。
- **下班倒计时**：自定义上下班时间与每周工作日，实时展示剩余时间和当日进度。
- **今日已赚**：根据月薪、月计薪天数与当天工作进度估算；支持自定义货币符号；不填写月薪时自动隐藏，不收集薪资数据。
- **待办与提醒**：创建、编辑、完成、筛选和删除待办，可分别选择提醒日期与时间。
- **不会错过的提醒**：到点后窗口自动恢复并置前，多颜色闪烁并周期播放简短提示音，直到用户点击确认。
- **专注模式**：提供 25、50、90 分钟快捷计时；会话本地持久化，结束后置前提醒休息，直到确认。
- **天气**：通过 Open-Meteo 查询指定城市的当前天气，无需 API Key；网络波动时自动重试并回退到三小时内的本地缓存，避免长期展示过期天气。
- **深浅主题**：支持跟随系统、深色与浅色主题。
- **中英双语**：支持跟随系统、简体中文与 English，可在设置中随时切换。
- **英语学习中心**：点击顶部 `EN` 按钮先进入学习中心；“单词本”在本机跨天汇总五种模式实际刷过的单词、音标、释义、例句、词库、模式和学习次数，“错题本”记录英译中、中译英与拼写模式的错词、最近答案和累计错误次数。点击“精简学习”才会打开紧凑学习窗；macOS 与 Windows 均只让背景跟随悬浮窗透明度，核心内容始终清晰。
- **可选单词词库**：英语学习默认使用《新概念英语》第二册，也可在设置中切换到新概念三、四级、六级、雅思或全部公共词库。
- **股市悬浮窗**：默认展示上证指数、深证成指和创业板指，可添加最多 12 个 A 股自选代码；小窗每 5 秒刷新并复用悬浮窗透明度，断网时保留最近行情。
- **在线检查更新与 Web 端入口**：每天最多查询一次 GitHub Releases，也可在“关于”页手动检查、一键打开对应平台安装包或访问 [Backlight Web 端](https://admin.asbacklight.cn/)。
- **统一账号入口**：登录和注册从聊天页移至独立账号中心；登录一次即可共享聊天、好友、工作云盘和全能翻译，退出账号时相关在线服务同步退出，工作台会展示当前昵称。
- **实时聊天、好友与窗口互动**：按精确用户名/用户 ID 添加好友、处理好友申请和查看在线状态；文字消息、抖一抖和闪一闪均写入会话记录，互动优先展示昵称。
- **工作云盘**：复用同一账号浏览目录、搜索、新建文件夹、重命名、移动、删除、上传和下载文件，并展示账号的实时存储配额。
- **全能翻译**：登录后支持自动检测源语言及中、英、日、韩、法、德、西、俄、葡、阿多语言互译；展示账号每日额度，支持历史搜索、单条/批量删除和 Excel 导出。
- **本地优先**：设置、待办、薪资和专注状态只保存在本机；账号密码与访问令牌仅保留在当前运行会话内，不写入本地数据文件。

## 使用说明

1. 打开设置，填写上下班时间并选择工作日。
2. 如需“今日已赚”，再填写月薪与月计薪天数；留空或设为 `0` 即隐藏该卡片。
3. 填写天气城市。应用仅在刷新天气时向 Open-Meteo 发送城市查询。
4. 新建待办并按需添加提醒日期和时间。提醒触发后，点击提醒画面即可停止闪烁和声音。
5. 在专注卡片选择 25、50 或 90 分钟。计时结束后应用会持续提醒休息，直到确认。
6. 点击顶部“精简”切换 2×2 小窗；拖动窗口任意空白区域移动，拖动窗口边缘缩放，应用会记住精简尺寸。
7. 在“关于”页点击“检查更新”；发现新版后可打开 GitHub 下载对应平台安装包，也可从这里进入 [Backlight Web 端](https://admin.asbacklight.cn/)。更新仍由用户确认安装，不会静默替换应用。
8. 点击叉号会隐藏到系统托盘而不会结束提醒；左键托盘图标恢复窗口，右键选择“退出”才会彻底结束应用。macOS 若因菜单栏空间不足看不到托盘图标，可点击 Dock 中的工位岛恢复。
9. 点击顶部账号按钮登录或注册。邀请码为选填；登录后聊天、工作云盘和全能翻译共享会话，退出账号时三者同时退出。
10. 点击顶部聊天按钮，从好友列表直接进入会话；仍可手动输入用户 ID 聊天、抖动或闪烁对方窗口。详情见[实时聊天说明](docs/REALTIME_CHAT.zh-CN.md)。
11. 点击顶部云盘按钮浏览工作云盘，可新建目录并上传、下载、重命名、移动或删除文件。
12. 点击顶部 `EN` 按钮进入英语学习中心查看本机单词本与错题本；点击“精简学习”打开五种学习模式，并可在设置中选择所用词库。学习记录从安装此功能的版本开始生成。
13. 点击顶部 `文A` 按钮进入全能翻译；可查看每日额度、自动识别源语言、复制译文，并管理或导出当前账号的翻译历史。

## 技术栈与架构

- Go 1.23+
- [Wails v2](https://wails.io/) 桌面窗口与 Go/JavaScript 桥接
- 原生 HTML、CSS、JavaScript 前端，静态资源通过 `embed.FS` 打包进可执行文件
- JSON 本地持久化
- macOS AppKit 与 Windows Shell 原生系统托盘；平台原生窗口激活、通知与声音适配
- Open-Meteo 地理编码与天气接口
- Backlight 账号认证、翻译服务、好友协议、WebSocket 实时通信与对象存储直传

桌面客户端可在 `workday-island` 目录独立构建与发布；待办、倒计时等本地功能不依赖服务器，账号、聊天、翻译、英语在线词库与工作云盘功能使用 Backlight 服务。

## 本地开发

```bash
git clone https://github.com/asbacklight-justin/workday-island.git
cd workday-island
go mod download
go test ./...
go run .
```

`go run .` 适合快速调试 Go 端。若需要 Wails 开发热重载，可安装 Wails CLI 后执行 `wails dev`。

数据默认位置：

- macOS：`~/Library/Application Support/WorkdayIsland/data.json`
- Windows：`%AppData%\WorkdayIsland\data.json`

完整构建、打包和发布说明见 [构建指南](docs/BUILD.zh-CN.md)。

## 隐私与联网

待办、提醒、薪资、工作时间、专注记录、英语单词本和错题本只写入本机 JSON 文件。天气访问 Open-Meteo，行情访问东方财富公开接口，版本检查访问 GitHub；用户主动使用账号、聊天、翻译、英语学习或工作云盘时，相应数据会发送到 Backlight 服务。应用没有遥测或广告 SDK。详情见 [隐私说明](docs/PRIVACY.zh-CN.md)。
